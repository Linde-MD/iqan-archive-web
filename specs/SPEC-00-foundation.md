## 3. 功能与交互规则

基础 UI 仅提供项目创建、列表、存储状态与能力边界提示，不显示伪造版本图或未实施操作按钮。

领域类型实现见 `src/domain/model.ts`，校验/命令见 `src/domain/graph.ts`：

- **项目**：稳定内部 ID、必填名称/零件号、兼容旧双目录提示字段、递增修订号。零件号非全局唯一键。
- **版本节点**：稳定内部 ID、同项目唯一完整版本号（含日期文本、去首尾空白、连续空格/Tab 归一、区分大小写）、说明、任务及放行时间；本地文件按当前扫描自动匹配，不从版本文本/修改时间推断关系。
- **文件匹配（2026-10-30 修订）**：文件名解析与当前扫描结果仅作会话派生状态，以当前项目零件号+完整版本匹配，不属于领域图或 JSON。数据库 v3 移除旧文件表，保留图与绑定。登记只创建缺失节点，详见 SPEC-01 AC-14–17。
- **图关系**：显式无环父子边；新版本仅推进明确目标分支（包含当前头作为父节点），合并至少双父，保留源分支头，不合并文件。
- **分支**：稳定 ID、项目 ID、名称、头节点引用、可编辑说明及颜色。名称与颜色需求已确认；说明字段为建议，完整字段待细化。
- **任务**：稳定 ID、项目 ID、必填名称、说明、可空 Loop ID。节点最多一个同项目任务；允许跨分支/不连续分组，投影保留所有真实边和端点映射/分支头摘要。删除任务只解除关联；初始全部版本，展开状态不持久化。
- **放行**：目标加所有可达祖先，记录首次放行时间，不记人员，重复操作幂等。撤销有已放行后代则拒绝，不回撤祖先；已放行版本号/父边锁定，可编辑说明与任务，本地文件独立维护、不锁定。
- **目录配置与绑定**：每项目分别保存工程、软件对比文档的本机授权句柄。绑定后自动保存并显示/复制实际目录名（非完整路径），取消手填地址与手动保存；句柄/权限/路径不属于可移植 JSON。旧 `engineeringDirectoryHint`/`wordDirectoryHint` 仅数据库兼容保留，不导出、不显示或作为权限依据。

### 任务与 Loop 卡片的关联结构（REQ-020）

用户确认首版仅手工填写 Loop 看板卡片 ID，同项目唯一；任意文本、去首尾空白、区分大小写，空值转 null，最多 16 个 Unicode 码点。不提供卡片链接、登录、API 或同步。以下字段已实现：

| 字段 | 草案类型/约束 | 用途 |
| --- | --- | --- |
| `id` | 稳定内部 ID | 节点 `taskId` 的引用目标，不使用 Loop ID 替代 |
| `projectId` | 稳定项目 ID | 限制节点关联与外部编号唯一性的项目范围 |
| `name` | 字符串 | 本地任务名称，不声称自动匹配 Loop 卡片标题 |
| `loopId` | `string \| null` | 用户录入的卡片 ID，如 `1479-1`；null 表示未关联，非空值同项目唯一 |

- 不强制所有任务来自 Loop；无关联的任务仍可使用。`loopId` 保留字符串语义，不数值化、不拆成父子任务编号，不从示例推导正式正则。
- 更改/清空 `loopId` 仅编辑本地关联元数据，不修改内部任务 ID、节点 `taskId`、图关系、任务归属或放行状态，也不修改远端 Loop 卡片。
- 不同项目可使用相同 Loop ID；同项目冲突须拒绝保存并指出已有任务，不按编号自动合并或重定向节点。多个未关联任务的 null 不视为重复。
- 唯一性在领域与 Dexie `[projectId+loopId]` 复合唯一索引一致保证；null 不形成唯一索引项，允许多个未关联任务。Q-018 已由第八轮确认，按码点计长而非 UTF-16 长度。
- 关联只是用户维护的编号映射，不存远端认证信息，也不能验证卡片存在、最新状态或访问权限。展示归 SPEC-02，持久化/迁移归 SPEC-03。

### 删除与存储契约

- `planDeletion` 提议子节点用被删节点全部父边替换、保留其他父边并去重；根删除后子节点可成根。可手改，提交须无环、同项目、无悬空；受影响分支须明确指定新头或删除分支记录。
- `applyDeletion` 不删除磁盘文件；只清除节点及相关边。已放行节点无论是否叶子均需二次确认并输入版本号；不能改已放行子节点父边。UI 二次弹窗归 SPEC-02，基础命令要求确认凭据。
- 存储在同一 Dexie 事务中读取当前快照、验证期望修订、执行变更并跨表保存；旧标签页冲突明确拒绝，不静默覆盖。保存失败传播至 UI 错误区域，不吞掉异常。
- 第八轮首次 schema v1；v2 新增独立本机绑定表、检查版本归一化碰撞；当前数据库 v3 移除旧文件表，保留图与绑定，旧文本不重写，未知未来版本拒绝打开。配置快照 schemaVersion 2 仅含项目元数据与图，排除目录提示/文件/句柄/二进制/命令/临时选择。
