## 1. 目标与范围

按项目授权并扫描工程/软件对比文档目录，自动关联已有版本，或从选中文件创建缺失版本；不读取工程内容、不修改磁盘文件、不执行本机程序。允许修改项目零件号，完整图编辑归 SPEC-02。

### 2026-10-30 自动关联修订（当前规范）

本修订替代下文历史验收记录中的“登记文件快照/显式重绑/文件引用放行锁定”规则；旧验收证据不代表本修订已通过。

- 匹配键为当前项目零件号 + 归一化完整版本号；零件号保留前导零，版本区分大小写。合法候选自动关联已有节点，无需登记或写入数据库。同一版本多个文件全部列出，不按日期或顺序任选一个。
- “登记”仅从选中文件创建尚不存在的版本节点；相同完整版本只创建一次。节点未放行、无父边、不推进分支；已有节点（含已放行）不会被修改。全选只覆盖合法且尚无版本的候选。
- 扫描与关联是当前会话的派生状态，不保存文件名/相对路径或扫描缓存，不进入项目 JSON。扫描成功后以普通次要文字提示缺少源文件的版本数及版本号，无红色警报，不阻止图编辑、放行或导出；未扫描、扫描失败/取消与“缺少文件”分别表达。
- 换目录、解除绑定或重新扫描先清空旧结果；仅完整成功扫描才用于缺失判断。项目/版本变更后按最新图重算；零件号修改后原扫描失效，要求重新扫描。
- 项目零件号可编辑，trim 后非空；稳定项目 ID、节点/边/分支/任务/放行状态及本机绑定不变。不会重命名磁盘文件；以后扫描按新零件号匹配。使用项目修订号防止并发覆盖，失败保留输入并明确反馈。
- 删除旧的文件引用重绑界面。定位只使用当前扫描结果中的工程相对路径；打开/对比前仍须明确选取多候选中的具体文件并重新校验。
- 数据库升级 v3：移除旧 `files` 表，保留完整版本图与本机绑定；仅移除可由扫描重建的文件元数据，绝不删除磁盘文件。配置快照 schemaVersion 2 只包含项目身份/名称/零件号/修订号、全部节点/边/分支/任务，不含旧目录提示、句柄、路径或本地关联。SPEC-03 的完整 JSON UI 仍未实施。

## 2. 文件名与版本身份（修订 Q-002/Q-005）

- 零件号只含数字，位数不限，保留前导零；与当前项目零件号精确匹配。
- 工程扩展名 `.idax/.idsx/.idvx` 不区分大小写，拒绝重复扩展名。
- 零件号后、扩展名前的完整文本是软件版本号。以 V/v 开头，后续只允许 ASCII 字母、数字、空格/Tab、短横线和点，至少有一个后续字母或数字；无固定数字分段。
- 字段间可有多个空格/Tab；去首尾空白，版本内部空格/Tab 连续段统一为一个普通空格。版本仍区分大小写，原始文件名不改写。
- `14798046801 V1.0-3 20261022.idax` → 零件号 `14798046801`，完整版本 `V1.0-3 20261022`。
- `V1.0-3 20261023` 是另一个版本节点。数字日期样式文本可属于版本号，不要求存在，也不单独校验日历日期。磁盘修改时间不决定身份/关系。
- 此结论替代早期“不同文件名日期属于同一节点”的误解；用户当时以为日期指磁盘修改时间。完整版本常显，关系永不从版本文本推断。
- 失败保留原始文件名和明确原因，不登记；用户在磁盘修正后重扫，不提供自动猜字段。

## 3. 授权、扫描与预览登记

- 两个独立角色：工程目录、软件对比文档目录。移除手填地址与保存提示按钮；授权绑定成功后自动持久化句柄，由实际句柄只读显示“已绑定目录：目录名”，提供复制目录名按钮，明确“仅目录名，非完整路径”。浏览器无法获得完整本机路径，不拼接或猜测；复制失败明确报错，允许手动选择文字复制。无绑定时显示“未绑定目录”并禁用复制。目录标题、操作及空态均使用业务名称。
- 用户点击选择目录，只请求只读权限；取消、权限拒绝或持久化失败均不替换旧绑定和显示名称，只有保存成功后更新界面。句柄仅在本机 IndexedDB 独立绑定表保存，禁止进入配置快照/JSON；解除绑定后清除名称显示，不删除原文件或引用。
- 刷新只检查权限，不自动弹授权；用户点击重新授权。支持明确的未绑定/需授权/可用/不支持/失败状态，可解除本机绑定。
- 递归扫描，仅枚举文件名和相对路径，不读二进制；两类扫描单次最多枚举 5000 个条目（含目录和不支持文件），第 5001 个中止、清除本次预览，不提交部分结果。支持取消和计数；迭代遍历避免深递归栈。
- 工程扫描显示自动关联/可创建版本/解析失败/零件号冲突；仅可选合法且没有对应版本的候选。确认后事务创建版本，修订冲突拒绝并要求重新读取。
- 扫描预览提供“全选可登记项”“全不选”和表头复选框；覆盖本次全部预览行（含局部滚动区外），跳过非法/零件号冲突/已有版本项。表头派生未选/部分选中/全选状态，显示已选数/可登记数/总数；忙碌或无候选时禁用，无选择时禁用清空/登记；重扫、换目录/项目清空旧选择，登记成功清空，批量选择不入库。
- 新完整版本创建未放行、无父节点、不推进分支；已有完整版本自动关联全部匹配文件，不新增快照实体，不受放行锁限制。
- 软件对比文档首版仅扫描 `.doc/.docx`（大小写不敏感），按项目显示相对路径列表，不持久化扫描缓存、不自动关联版本。后续通过 Launcher 请求本机 Word 打开原文件；不提供假打开按钮或下载替代。
- 工程/软件对比文档原始文件不入库、不上传；扫描列表可重新获取，失败不伪报空目录。

- 自动关联文件按当前扫描中的工程角色+相对路径精确定位。多个候选逐条列出，用户明确选择要检查的文件。

- 项目切换卸载旧工作区并取消扫描，不混入其他项目结果；操作期间禁止切换。
