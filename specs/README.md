# IQAN 工程版本管理工具 SPEC 索引

> 当前为第七轮增量更新后的框架：Launcher 已建立独立 Windows LSP 规格，并确认 C#/.NET/WinForms、自包含与 SDK/CLI 技术方向，尚未实现或定稿运行时/安装器。样式仍以适用的 UI/UX Pro Max 建议为主，DESIGN.md 为辅助。保留 GitHub Pages 静态前端、Loop 手工 ID 及可选按需启动器边界；网页无可靠执行结果回传。手册参数已核对，所有实机验收未执行。

## 目标与边界

- **目标用户与场景**：IQANdesign 工程维护者需要按项目整理 IQAN 工程版本，并通览、编辑项目版本分支图。
- **目标闭环**：管理项目及其软件零件号；根据受支持的文件名提取零件号/版本；在图上浏览并编辑版本节点、分支与合并。
- **核心范围**：多项目；文件名解析；工程/Word 对比文档双目录配置与授权绑定；Dexie.js 持久化；单项目 JSON 配置导出恢复；图形平移缩放、增删改、分支信息与颜色；任务聚合/全部版本两模式；放行及全祖先传播。展开的版本节点常显版本号，不显示零件号；改动说明在悬浮/焦点时查看。
- **已确认文件边界**：工程和 Word 文件保留在原目录，JSON 只备份配置与元数据，不携带二进制或目录授权；恢复后重新绑定目录。
- **任务外部关联**：任务一般来自 Loop 表格看板；手工填写卡片 ID（如 `1479-1`），同项目内唯一，与本地稳定任务 ID 分开。聚合标题与任务/节点详情展示关联编号，随配置备份；允许没有 Loop 关联的本地任务。首版不提供卡片链接、Loop 登录、自动读取或同步，不声称已验证卡片存在或权限。
- **对比需求**：选中两个版本节点后右键对比；先规划显式双选、对象/顺序预览及状态，使用 IQANdesign 的 `-diff` 外部查看器，不在网页解析工程内容。
- **可选本地能力**：用户安装 Windows 自定义协议启动器后可请求单文件打开和双文件对比。Windows 按需激活，本机校验/确认后调用 IQANdesign；没有本地 HTTP/常驻服务。未安装也能使用网页核心功能；协议名和安装发布细节待定。
- **未定业务规则**：撤销放行和改链、任务跨分支呈现、Word 关联规则、协作、搜索/过滤及图布局保存待定。
- **本轮不假定**：解析/修改 IQAN 二进制、Web 内部 diff 引擎、内容合并、与 Git 互操作、云端协作、自动生成 Word 报告。手册展示的外部对比能力与本工具能启动它是两个条件。
