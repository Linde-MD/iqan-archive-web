## 1. 目标

用户选中两个版本节点后，可从右键菜单发起对应工程文件的 IQANdesign 对比。对比由本地 IQANdesign 查看器完成，不是在 Web 中解码二进制，也不是图关系合并。

本 SPEC 独立承载本地操作，避免持续扩充图形画布和目录解析文档。此前 SPEC-01 的打开能力约束、SPEC-02 的通用菜单规则仍有效，保留原验收编号。

- 既有单节点打开需求 REQ-010 使用同一本地能力边界，单选不误触双文件对比。
- 不包含：自动合并工程、网页内部 diff 查看器、文本导出链、第三方 diff 工具、生成软件对比文档、报告保存/关联与对比历史。未来需要时单独确认。

## 3. 已核实的手册契约

来源：[本地 IQANdesign 手册](../references/IQANdesign.pdf)，第 2 章 User Interface → File compare → Command line compare，印刷页 47–48。2026-10-29 对 PDF 文本流与用户截图进行交叉核对，示例为：

```text
IQANdesign.exe ProjectV1.idax -diff ProjectV2.idax
```

- 示例表达：程序后先传第一份工程，再传 `-diff`，最后传第二份工程；用于同一工程的两个版本对比。
- 手册还介绍了文本导出用于外部查看器的另一种途径；本需求不采用该途径，不擅自增加写文件行为。
- 手册示例验证范围只有 `.idax`；`.idsx/.idvx`、混合扩展名、跨 IQANdesign 版本、不同工程的支持情况、退出码、已有进程复用及图形窗口就绪信号均未由该段证明，见 Q-015。
- 手册参数说明不是本地启动能力：浏览器授权目录句柄不等于真实可执行程序路径，也不赋予运行进程权限。

## 4. 功能与交互规则

### 双节点选择

- 只接收两个不同的真实版本节点；任务容器、分支标签或隐藏节点的隐式全选不充当版本节点。任务模式先展开再显式选择版本。
- 建议采用 Ctrl/Cmd＋点击追加/取消选择，并提供键盘和不依赖修饰键的可见选择入口；焦点与选中状态区分，选择标识不覆盖版本号、分支颜色或放行标记。
- 右键已选节点时保留两个节点的选择；右键未选节点时建议切换为该单节点，避免用陈旧选择对比错误对象。该规则须通过交互测试，不能由图形库默认行为偶然决定。
- 菜单显示当前选择数量。0、1、超过 2 个节点不能发起对比，说明“请选择两个版本”；重复 ID、任务容器、跨项目选择均拒绝。
- 依手册同工程前提，本轮规划限制同一项目。项目相同不自动证明文件内部属于同一 IQAN 工程，兼容性仍受 Q-015 限制，不读取内部二进制来假装验证。

### 对比对象与顺序

- 显示两个节点的版本号及对应文件名；相同版本字符串的节点以稳定 ID/日期/文件名辅助区分，不把版本号当文件路径。
- 每个节点须从 SPEC-01 当前扫描自动匹配的候选中精确定位一个工程文件；多候选由用户明确选择，不能自动选“最新文件”。不依赖持久化文件引用；零件号改变/重扫/目录改变使旧预览失效。缺源文件仅阻止本次打开/对比，不阻止图编辑或放行。
- 按选择顺序确定“文件 A/文件 B”，不根据日期、版本号或图位置擅自判断基准/目标。唯一文件匹配且复检通过时直接请求 Launcher；异常处理面板允许交换 A/B。手册未证明左右窗格语义，不把 A/B 命名为已证实的左/右。
- 发起前重新检查两节点仍存在、同项目、文件引用未变且可访问；跨分支的同项目版本不因没有直接父子边而自动排除。
- 对比是只读意图，不修改图关系、任务、放行状态或源文件；不把“比较”解释为“合并”。

### 菜单与能力反馈

- 右键提供“对比所选版本”，支持键盘上下文菜单/更多操作入口，方向键、Enter、Escape 及焦点返回。
- 2026-11-06 交互修订：用户右键或工具栏明确选择打开/对比后，自动扫描并复检文件；唯一匹配且检查通过时按 SPEC-05 共享契约自动请求一次 Launcher，不先弹网页预览。缺文件、权限失效、多候选或项目修订变化时显示处理面板；多候选须明确选取，检查通过后请求。Launcher 本机逐次确认不变。异步扫描可能失去浏览器用户激活，自动请求不保证获准；图下方不再显示常驻“手动请求 Launcher”入口，未出现系统提示时检查安装及浏览器权限后重新发起操作，不以超时或页面失焦推断成功。浏览器仍可能弹外部应用确认。
- 网页只显示“已请求本地启动器，请查看系统提示”，不显示进程创建、工程已加载、比较完成。协议无可靠回传，不能用定时器、页面失焦或“用户说已安装”推断成功。
- 安装状态默认未知；始终可查看安装配置说明、重试和手动操作指引，不循环自动发起协议。未安装/被策略拦截可能无法自动区分，需如实说明；可捕获的网页激活错误明确反馈。
- 程序/归档根目录设置、实际文件校验、用户取消、启动失败在本机提示。无论安装与否，网页图管理、任务/放行和 JSON 功能继续可用。

## 5. 必要接口与协议集成约束

- 选择/预览输入：项目 ID、两个不同 node ID、有序 A/B 及精确文件引用；输出合法预览或可区分的选择、文件、权限、兼容性错误。
- 网页区分平台/协议版本支持、自报安装偏好及真正的本机验证：前两者都不证明已安装或 `-diff` 已实机通过。
- 仅由启动器本机配置指定 IQANdesign 程序；JSON 不携带 EXE 路径命令、参数模板或启动授权。目录提示和文件名视为不可信数据。
- 启动器使用受限的结构化调用，不拼接 shell 命令。对比参数列表保持 `[fileA, "-diff", fileB]` 顺序；程序路径、含空格/中文的文件路径、引号等由所选平台进程 API 处理并实测，不能据手册无空格样例推导转义方案。
- 网页仅编码操作、协议版本、项目 ID 和相对于 Launcher 归档根目录的文件路径。该相对路径由已绑定工程目录名称（首版要求为归档根目录的直接子目录）加上扫描得到的相对文件路径组成；浏览器句柄不提供 Windows 完整路径，网页不得拼接或猜测绝对路径。Launcher 在用户配置的归档根目录内解析并显示实际路径；项目 ID 仅标识请求上下文，不代表本机目录授权。不能发送 EXE/命令或借网页自报来源授权。启动器将任何来源请求视为不可信，每次本机确认与校验，详见 SPEC-05。
- 浏览器绑定可用于文件名浏览与预检，但不能提供启动器的本机目录映射；两者分别设置。网页权限不可用时不能谎称文件预检通过；启动器仍必须独立校验最终路径。
- 网页只生成冻结的 URI v1，并将所选路径保留在当前页面会话；临时选择不加入 Dexie.js/JSON，不增加对比历史。Launcher 的安装、注册、本机校验、确认和调用不属于本 SPEC 的 Web 实现。

## 6. 异常与边界

| 条件 | 行为 | 恢复方式 |
| --- | --- | --- |
| 选择数量不是 2、重复节点或容器 | 对比不可发起，明确说明。 | 重新显式选择两个版本。 |
| 跨项目或两个节点指向同一文件 | 拒绝跨项目；同一文件提示无需比较，不静默替换对象。 | 重新选择，或修正文件引用。 |
| 节点文件缺失/多候选/目录未授权 | 保留选择并指出具体失败对象。 | 重绑、重新定位或取消。 |
| 预览后节点/文件引用变化 | 重新校验并提示预览失效，不使用旧参数。 | 更新预览后确认。 |
| 启动器未安装/被阻止/状态未知 | 如实展示无可靠检测/回传，不假报成功。 | 安装指引、用户主动重试或手动打开/对比。 |
| 格式/版本兼容未核实 | 标记未验证，不推广手册 `.idax` 示例到其他格式。 | 按 Q-015 实机核实后决定开放范围。 |
